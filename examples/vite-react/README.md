# Example: a club's registration site on @eventkit/sdk

Sign up, start a team through the event's participant link, invite teammates,
register (with the payment receipt when the event takes payment at
registration), RSVP, and show the check-in QR code.

```bash
cp .env.example .env    # API URL, event id, the event's API key, a participant link token
npm install
npm run dev
```
